在实验B中，当Fastjson看到@type时，会按序执行以下动作：

  1. 读取@type的值：com.zhuangjiewei.two.Cat
  2. 加载类：通过反射加载com.zhuangjiewei.two.Cat
  3. 实例化：无参构造函数被调用。
  4. 属性赋值：属性对应的Setter被调用。

3.总结

Fastjson的AutoType机制提供了这样一种能力：

根据用户在 JSON 字符串中提供的任意类名（通过 @type 字段），通过反射机制，自动去加载并实例化该类，并调用该类的 Setter 方法进行赋值。**

这样就为漏洞形成提供了条件：

如果用户将 @type 的值替换为一个 Java 标准库中存在的、在 Setter 方法中包含危险操作的类，那么在反序列化过程中，危险操作就会被自动触发！
